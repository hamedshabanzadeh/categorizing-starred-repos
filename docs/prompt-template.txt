این یک فایل inbox.json از ریپوهای تازه استارشده‌ی گیتهاب است، به‌همراه ساختار دسته‌بندی فعلی پروژه (categories.yaml).

برای هر آیتم داخل inbox.json، این اطلاعات را مشخص کن:

- id: همان id عددی که در ورودی آمده (بدون تغییر، برای تطبیق دقیق)
- category: یکی از دسته‌های موجود در categories.yaml (تا حد امکان از دسته‌های موجود استفاده کن، دسته‌ی جدید نساز مگر واقعاً لازم باشد)
- subcategory: زیردسته‌ی مرتبط (اگر موجود نبود، رشته‌ی خالی بگذار)
- purpose: یک جمله‌ی کوتاه که دقیقاً می‌گوید این ریپو چه کاری انجام می‌دهد
- description_fa: توضیح کوتاه و روان به فارسی درباره‌ی کارکرد پروژه (۱ تا ۲ جمله)
- tags: چند برچسب کوتاه مرتبط (آرایه‌ای از رشته‌ها)
- confidence: "high"، "medium" یا "low" — میزان اطمینانت از درستی این دسته‌بندی
- needs_review: true اگر اطلاعات کافی برای دسته‌بندی مطمئن نداشتی، در غیر این صورت false
- در صورتی که هیچ‌کدام از دسته‌های موجود واقعاً مناسب نبود، این دو فیلد را هم اضافه کن:
  - suggested_new_category: true
  - suggested_category: "<نام دسته‌ی پیشنهادی>"

هرگز از دسته‌ی عمومی "Other" استفاده نکن؛ اگر مطمئن نیستی، confidence را "low" و needs_review را true بگذار.

خروجی نهایی را به این صورت ارائه بده:

- اگر امکان ساخت فایل قابل‌دانلود داری، خروجی را دقیقاً با نام فایل `ai_output.json` بساز و برای دانلود ارائه بده.
- اگر امکان ساخت فایل نداری، خروجی را فقط و فقط به‌صورت یک آرایه‌ی JSON معتبر در یک بلاک کد بده (بدون هیچ توضیح اضافه، بدون متن قبل یا بعدش) تا بتوانم آن را کپی کرده و خودم با نام `ai_output.json` در پوشه‌ی `data` ذخیره کنم.

در هر دو حالت، ساختار هر آیتم دقیقاً باید این‌گونه باشد:

[
  {
    "id": 123456789,
    "category": "AI & LLM Tools",
    "subcategory": "AI Agents",
    "purpose": "...",
    "description_fa": "...",
    "tags": ["ai", "agents"],
    "confidence": "high",
    "needs_review": false
  }
]
